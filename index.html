ARQUITECTURA MODULAR

Extiende tu LMS al Instante mediante ZIP

Nodal Learning está construido con una arquitectura física de plugins. Sube un archivo ZIP para instalar pasarelas de pago, herramientas de videoconferencia u otras funcionalidades sin tocar una sola línea de código del núcleo.

  • Detección y Carga Dinámica: Autocarga PSR-4 del namespace del plugin y registro del Service Provider en tiempo de ejecución.
  • Migraciones Automáticas: Si el ZIP contiene migraciones de base de datos, el sistema las ejecuta inmediatamente al instalar.
  • Activación Seguro: Habilita o deshabilita los complementos desde el panel administrativo con un solo clic asíncrono.

Instalación en 5 Minutos

Nodal Learning cuenta con un asistente gráfico que realiza la configuración inicial sin complicaciones técnicas.

Extrae el paquete en tu Hosting

Descarga el archivo `Nodal_Learning_Instalable.zip` y súbelo al directorio principal de tu hosting compartido (ej. `public_html`). Descomprímelo y accede a tu dominio en el navegador.

El sistema detectará que no está instalado y te redirigirá automáticamente al asistente visual:

http://tu-dominio.com/nombre-carpeta/public

Elige tu motor de datos

El instalador te permitirá configurar la base de datos de manera gráfica:

  • 💾 SQLite (Recomendado): Crea un archivo de base de datos local seguro al instante. Ideal para hosting básico.
  • 🛢 MySQL / MariaDB: Ingresa el servidor, puerto, usuario y clave para proyectos de alta demanda.

El asistente creará las tablas y configurará las llaves de encriptación por ti.

Crea tu Cuenta de Administrador

Ingresa tu nombre, correo institucional y define la contraseña del administrador del sistema.

Al hacer clic en "Finalizar Instalación", el asistente grabará la configuración, creará el archivo de seguridad y te dará acceso inmediato al panel de administración.

🚀 ¡Listo para Enseñar!

Tu sitio ya está en línea. Puedes iniciar sesión y configurar:

  • ⚙ **SMTP:** Carga tus credenciales de correo SMTP para los flujos de bienvenida y restablecimientos.
  • 🏢 **Identidad:** Carga el logo y nombre de tu institución.
  • 🔌 **Plugins:** Instala Mercado Pago o Zoom subiendo los módulos ZIP correspondientes.

Comienza a Enseñar Hoy

Descarga el paquete autoinstalable y monta tu propia academia en tu servidor en cuestión de minutos.
